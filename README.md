# Diagrams-Save

Unity 游戏框架设计图的历史保存仓库。

仓库主要包含 `框架图/框架图.drawio`，记录早期的 UI、Controller、Model、System、Query、Command、事件总线、MVX 方案，以及玩家输入到逻辑、输出、环境/AI 的循环。这份图是 SSFramework 的思想前身，已经成为历史设计资料，不代表当前实现。

## 打开方式

使用 [diagrams.net](https://www.diagrams.net/) 或 draw.io 打开：

```text
框架图/框架图.drawio
```

仓库没有可执行程序或构建步骤。

## 当前状态

已冻结的历史设计稿，最后一次 push 为 2022-06-16。后续框架实践主要转移到 [SSFramework](https://github.com/heroliss/SSFramework)。
